# Liste de vérification avant livraison

À compléter pour chaque remise ou version importante. Adapter les vérifications aux exigences de la livraison concernée.

## Suivi et documentation

- [ ] Issues prévues pour la livraison terminées
- [ ] Pull Requests correspondantes fusionnées
- [ ] Branche `main` synchronisée et cohérente
- [ ] Fichiers requis présents aux emplacements prévus
- [ ] Cas d'utilisation, règles métier et scénarios d'exception à jour
- [ ] Diagrammes UML et sources Modelio à jour
- [ ] Rapport final conforme aux exigences de la remise
- [ ] Contributions des membres consignées

## Application et données

- [ ] Code Java compilé sans erreur
- [ ] Tests pertinents exécutés
- [ ] Schémas et données nécessaires disponibles
- [ ] JAR de livraison vérifié lorsqu'il est requis
- [ ] Fichiers temporaires et inutiles exclus des livrables

## Validation finale

- [ ] Version de livraison identifiable
- [ ] Cohérence entre exigences, UML, implémentation et tests vérifiée
- [ ] Livrables relus par l'équipe
